# Interface preview assets / 界面预览素材

`launcher-icon.png` is the Little Craft Launcher lantern icon used by this project. It is branding artwork, not an executable or an application source snapshot.

`lumina-home.png` (1280×840) and `lumina-home-small.png` (760×480) show the native Qt Quick application in its Lumina theme. They were captured on Linux with Qt 6.8.2, a private virtual display and software rendering. The instance records and `LuminaDemo` account are synthetic demonstration data; the images do not show real credentials or game saves and do not prove Microsoft authentication, game launch, Windows behavior or rendering frame rate. Both files are copied byte for byte from the original captures.

`launchpad-home.png`, `winui3-fluent-home.png` and `material3-home.png` (each 1280×800) show the development Launchpad, rebuilt Windows 11 and rebuilt Material 3 themes. They were captured on 2026-11-08 on Linux with Qt 6.8.3 and software rendering, using an isolated data directory. The instance records and the account “方块玩家” are demonstration data, without game files or login credentials.

`koring-home-idle.png` (1280×840) shows an empty development window in the Koring theme. It was captured on Linux with Qt 6.8.2 and software rendering using an isolated empty data directory. Its wallpaper is third-party artwork; see the Koring credits below.

All preview PNGs are original captures copied byte for byte, without cropping, compositing or pixel changes. No preview establishes real authentication, game launch, Windows acceptance or rendering frame rate. Screenshots may show development version numbers and can differ from a future public release.

新增截图分别展示启动台、重做后的 Windows 11、Material 3 和 Koring 主题；均为隔离数据或空状态的原始截图，不含真实账号凭据或私人存档。标题栏中的版本号用于开发预览，不表示本发布仓库已经提供该版本的安装包。

截图用于介绍开发中的界面；UI 仍在升级，正式版本以发布说明为准。图中的实例与账号均为演示数据，不是实际用户记录，也不是 Windows 或真实游戏验收结果。
